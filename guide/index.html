README 原文 · 补充参考

REFERENCE

星际矿站 · Star Miner

一款原创科幻放置经营游戏浏览器原型。玩家在 Aurora-1 星球上修复采掘器、运输线与晶体精炼厂，通过自动生产、设施升级、能源策略、科技研究与无人机事件扩展矿站。

纯前端实现：TypeScript + Vite + Three.js，零外部美术资源（纹理全部程序化生成），无后端、无账号，存档保存在浏览器 IndexedDB。

Star Miner is an original sci-fi idle / base-building browser game prototype: restore excavators, maglev transport lines and a crystal refinery on planet Aurora-1, then grow the station through automation, upgrades, energy strategy, research and drone events.

特性

  • 核心生产链：星尘采掘器 → 氦-3 采掘器 → 氘采掘器 → 磁轨运输线 → 晶体精炼厂
  • 四档能源策略（采掘优先 / 均衡运行 / 精炼优先 / 聚变模式）+ 能源站与能量储备池
  • 资源链扩展：同位素（氘采掘副产物）→ 反物质 → 暗物质（T3/T4 高级资源）
  • 研究中心与四分支科技树（T0–T4 共 29 个可研究节点，涵盖采掘 / 能源 / 运输 / 精炼）
  • 30 个成就（每 10 点成就 +1% 全局产量）
  • 转生系统：消耗资源获取星核，转生后基线重置但永久加成保留；转生仪式提供成就回顾
  • 星核商店：15 种永久加成物品（经济 / 生产 / 研究 / 设施 / 转生五类），购买等级跨转生保留
  • 无人机事件（A/B 二选一）、太阳风暴、投入型事件
  • 离线收益（8 小时上限）、IndexedDB 本地存档（v9）+ JSON 导入导出 + 节奏数据 CSV 导出
  • ~ 调试面板：改资源、等级、解锁、触发事件、模拟离线

  • 星图（starmap）：星系地图与矿区解锁进度

M2 · 同位素反应堆

消耗同位素的三个入口（全部走 T1-1 ConsumptionEngine 原子事务，墙钟驱动倒计时）：

Buff 激活（消耗同位素，对指定资源施加限时倍率，多 buff 乘法叠加，封顶 ×8）：

  • 催化过载：60 同位素，持续 10 分钟，全采掘 ×2 产量
  • 晶体共鸣：90 同位素，持续 5 分钟，精炼 ×1.5 产量
  • 同位素熔炉：40 同位素，持续 20 分钟，全采掘 ×1.5 产量（长时低增益）

深空探索派遣（消耗同位素，完成时发放奖励；每次仅限 1 路探索进行中）：

  • 近地小行星带：30 同位素，1 分钟，+4 反物质（低风险，稳定）
  • 柯伊伯带：80 同位素，3 分钟，+3 暗物质（中风险）
  • 蛇夫座深空：150 同位素，6 分钟，+10 反物质（高风险远征）

碎片兑换配方（消耗 A 产出 B，单次事务原子完成）：

  • 同位素催化兑换：25 同位素 → 300 信用点
  • 同位素结晶：40 同位素 → 8 晶体
  • 反物质湮灭：3 反物质 → 2 暗物质

反应堆活跃度 reactorActivity：0（待机）到 1.0（满载），驱动 Three.js 反应堆粒子流强度。buff 与探索越多、活跃度越高，无任何活跃项时归零。

M3 · 转生系统

点击侧边栏「转生」打开转生仪式面板。流程：预览 → 确认 → 仪式动画（4.2s）→ 基线重置。

星核计算公式 computeStardustEarned（纯函数，无最低门槛，任意转生均可触发）：

点数 = 晶体/100 + 同位素/20 + 反物质/5 + 暗物质/2 + 星尘/1000
      + 2 × Σ(设施等级 - 1)  +  5 × 研究项数
星核 = floor(点数 × 转生增幅器倍率)

信用点与能量不计入转生定价；M4 shop-prestige-amplifier 每级 +25% 转生收益，在 floor 之前乘入。

仪式动画阶段（4.2s 全屏冻结交互，OrbitControls 禁用 + 全屏遮罩防点击穿透）：

  • 0.0–1.6s 坍缩（collapse）：星体收缩
  • 1.6–2.4s 爆发（burst）：核心闪光 + 粒子外冲
  • 2.4–4.2s 重生（rebirth）：新星展开、世界淡入

转生后状态变化：

  • 重置：信用点、星尘、晶体、同位素、反物质、暗物质归初始值；所有设施等级回 1 / 锁定；研究清空；成就清空
  • 保留（转生层）：星核余额、转生等级、转生历史快照、星核商店购买等级（shopPurchases）
  • 保留效果：所有 onBaseline 永久加成 + M2 反应堆活跃 buff 不跨转生（buff 由 ReactorRuntime 内存持有，转生重置时清空）
  • 转生仪式提供「成就回顾」面板，展示转生前的基线层摘要与获得的星核明细

M4 · 星核商店

点击侧边栏「商店」打开星核商店面板。

15 种物品 · 5 大类：

类别数量物品

购买机制：

  • 成本公式：floor(baseCost × costMultiplier^level)，每级更贵
  • 每次购买 +1 级，达到 maxLevel 后满级不可再买
  • 走 T0-1 事务原子完成：只读校验 → 扣星核 → 升等级 → onPurchase 即时效果 → commit

前置依赖链：部分物品需先购买前置物品达到指定等级才能解锁（如「氘开采许可」需先买「氦-3 开采许可」达 1 级；「高级研究授权」需先买「研究资助」达 2 级）

四态购买状态：

  • 可购买（purchasable）：星核充足 + 前置满足 + 未满级
  • 锁定（locked）：前置未满足（按钮灰显）
  • 满级（maxed）：已到 maxLevel
  • 星核不足（insufficient）：余额低于当前级成本

跨转生保留：shopPurchases 存于 prestige 层，转生不重置购买等级。效果叠加：

  • onPurchase 即时效果：购买时立即生效（mutate 事务工作状态），持续到下次转生
  • onBaseline 永久效果：转生后基线层叠加，由 applyShopBonuses 在 buildPrestigeBaseline 末尾调用
  • 派生乘子（产量、收入、研究折扣等）由 shopBonuses.ts 派生函数读取 prestige.shopPurchases，遵循 achievementProductionMultiplier 先例（不新增 GameState 字段）
