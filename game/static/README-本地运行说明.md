# 《星际矿站》Web 原型 · 本地运行说明

版本：v0.4（科技期：研究中心 + 科技树 + 能源系统 + 同位素 + 物流无人机 + 成就）

## 运行方式（推荐）

不要直接双击 `index.html`（浏览器会因跨域限制无法加载资源）。请在 `StarMinerWeb/` 目录启动一个静态服务器，例如：

```powershell
# 方式一：使用 Node（如已安装）
npx --yes serve .

# 方式二：使用 Python
python -m http.server 8080
```

然后用 Chrome 或 Edge 打开 `http://localhost:8080/`。

## 操作说明

- 1 / 2 / 3：切换能源策略（采掘优先 / 均衡运行 / 精炼优先）
- 升级按钮下方会显示升级后收益与预计回本时间
- 解锁研究中心后，左侧「研究」可查看四分支科技树（采掘/能源/精炼/运输），研究消耗晶体
- 能源站产出能量：设施按策略消耗，能源不足时全设施减产；研究「能源储备」后可用「释放储备」
- 左侧「成就」查看首批 30 个成就，每 10 点成就 +1% 全局产量
- 交易面板可分别开启「自动出售星尘矿 / 自动出售晶体」，各自可设保留数量，超出自动卖出
- U：升级或解锁当前选中设施（点击中央场景设施切换选中）
- M：打开存档管理（导出 JSON / 导入 JSON / 导出节奏数据 CSV）
- 左侧「星图」：查看星系地图与矿区解锁进度
- `~`：打开调试面板（改资源、等级、解锁、触发事件、模拟离线）
- Esc：关闭弹窗

## 事件说明

- 无人机事件：首个事件约 2 分钟后出现，之后每 3–5 分钟一次，左下角通知条二选一（A：+50 信用点；B：全设施 ×1.5 速度 30 秒）
- 太阳风暴：全设施速度 -20%（均衡策略 -10%），持续 1 分钟
- 投入型机会：消耗 200 信用点，永久提升采掘速度 +5%（全局仅一次）

## 成长门槛

- 设施升到 3 级以上需要消耗晶体
- 第二矿区（氦-3）解锁需要 1250 信用点 + 20 晶体
- 第三矿区（氘-3）解锁需要 3000 信用点 + 100 晶体

## 存档

- 自动保存到浏览器 IndexedDB（每 30 秒、关键操作、页面隐藏时）
- 建议定期「导出 JSON」备份；浏览器清理数据会丢失存档
- 导入 JSON 前会显示预览，确认后才覆盖当前进度

## 常见问题

- 场景空白：确认浏览器已启用 WebGL 硬件加速；Chrome/Edge 最新版均支持
- 存档丢失：可能是浏览器清理了站点数据，请用之前导出的 JSON 重新导入
