# 《星际矿站》v0.4 规划：科技期（科技树 + 能源系统 + 成就）

> 成文时间：2026-08-08；基于 v0.3 版本基线开发。

## 一、范围

v0.4 纵向加深：研究中心 + 科技树（基础研究 + 四分支 T1–T2 共 17 个可研究节点）、真能源资源系统（独立能源站 + 能量储备池 + 释放储备）、新资源「同位素」、物流无人机系统、首批 30 个成就（成就点数 → 全局产量）。版本 v0.4，存档 v5 → v6；T3/T4 节点灰显占位，随后续版本开放。

## 二、关键设计

### 研究中心解锁
- 条件：累计产出 ≥ 50 晶体 + 第二矿区已解锁。
- 流程：满足条件后的下一次无人机事件额外出现「C · 发现古代数据核心」选项，选择后解锁研究中心、科技树入口与能源站。

### 科技树
- 基础研究（15 晶体）→ 四分支。
- 采掘：强化钻头（20，采掘 +15%）、矿脉探测（25，按期望 +10%）、自动采掘阵列（80，速率按等级 +1）、稀有矿同位素（100，5% 期望产出同位素）。
- 能源：高效涡轮（20，能耗 -10%）、太阳能板（25，均衡 +5%）、能源储备（80，储备池 200 + 释放储备）、过载保护（100，不足惩罚 -20% → -10%）。
- 精炼：高效催化（20，精炼 +20%）、配方优化（30，4:1 → 3:1）、副产品回收（80，精炼时 +20% 星尘）、晶体品质（100，售价 +25%）。
- 运输：磁轨加速（20，+30%）、扩容货舱（25，容量 +50%）、多轨并行（120，速度 ×2）、无人机配送（100，0.5 星尘/秒直送精炼缓冲）。
- 研究消耗晶体，前置必须已研究；重复研究/前置缺失/晶体不足均拒绝。

### 能源系统
- 能源站：第 6 个设施（场景 x=18，蓝绿能量核心），成本 1000 信用点 + 15 晶体，基础产出 1.0 能量/秒，升级 +20%/级。
- 每个在线设施基础能耗 0.2/秒 × 策略倍率（均衡 ×1；采掘优先：采掘 ×0.6、运输/精炼 ×1.3；精炼优先：精炼 ×0.6、其余 ×1.3）。
- 盈余进储备池（研究能源储备后，容量 200）；不足时全设施 -20%（过载保护后 -10%）。
- 释放储备：消耗 100 能量 → 30 秒全设施 ×1.2，冷却 60 秒。
- 能源站未解锁时不计算能源（无惩罚）。

### 成就（首批 30 个）
- 生产 8 / 建设 5 / 科技 6 / 事件 5 / 探索 3 / 隐藏 3。
- 每个成就奖励信用点 + 晶体；每 10 点 +1% 全局产量（永久）。
- 由生命周期统计驱动：累计产出、累计收入、事件数、研究数、升级数、离线收益等。

## 三、接口与数据

- `types.ts`：资源增加 energy/isotope；设施增加 energyStation；GameState 增加 stats/research/researchCenterUnlocked/energy/isotope/achievements/energyReleaseUntil/energyReleaseCooldownUntil；存档版本 6。
- `config.ts`：GAME_VERSION v0.4、科技节点表（29 个，T0–T4）、成就定义表（30 个）、能源常量。
- 新模块：`research.ts`、`energy.ts`、`achievements.ts`。
- 生产链：科技倍率、能源收支、同位素、物流无人机通道、副产品、3:1 配方、品质售价、成就全局倍率。

## 四、测试计划

- 单元测试：科技（前置/成本/重复/T3-T4 锁定）、能源（产出/能耗/储备/释放/不足惩罚/过载保护）、成就（判定/计数/倍率）、生产统计、存档 v6 迁移（v1–v5 → v6）与非法字段。
- 浏览器验收：研究中心解锁事件流、科技树研究、成就面板、能源站场景、布局、离线含能源结算。
- 回归：原 81 项 + 新增约 40 项，目标全绿；tsc + vite build 通过。

## 五、默认与假设

- 同位素 v0.4 仅收集与成就计数，无消耗口（随 T3/T4 后置）。
- 矿脉探测/同位素按期望值实现，无随机抖动。
- 太阳能板定义为均衡策略 +5%；过载保护作用于能源不足惩罚。
- 无人机配送实现为独立转运通道，不重构三矿区库存模型。
- 转生/星核商店/新星球不在 v0.4（stats 已预留累计数据）。
