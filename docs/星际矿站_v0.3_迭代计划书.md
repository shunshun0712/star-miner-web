# 《星际矿站》v0.3 迭代计划书（豆包试玩反馈整改）

> 成文时间：2026-08-07；对应代码：`game/`（TypeScript + Vite + Three.js）。

## 一、背景与反馈核验

豆包对 v0.2 构建进行试玩后给出 12 项反馈（2 项 P0、5 项 P1、5 项 P2）。逐条对照源码核验后：

- **代码确认属实**：运输线空窗期（精炼厂未建成前运输线不转运，且动画照常播放）、版本号不一致（界面硬编码 v0.1）、缺自动出售 / 升级预览 / 分步引导 / 能源策略反馈、第二矿区 29:59 卡线偏紧、事件反馈弱、无成就系统。
- **需复现验证**：离线收益弹窗点击问题（本次在最新构建上用真实鼠标点击复测，弹窗按钮 / Esc / 遮罩均正常，原问题未复现；已做防御性加固并加入回归用例）。
- **已修复**：设施点击命中范围、部分弹窗堆叠。

## 二、本轮范围

P0 + P1 全部落地，P2 顺手修；成就 / 里程碑系统推迟到 v0.4。

## 三、关键变更

### P0

1. **离线收益弹窗加固**：按钮显式 `type="button"`、遮罩点击关闭、弹窗打开时禁用 OrbitControls 指针监听（关闭后恢复）、自动化点击回归。
2. **运输线空窗期**：运输线改为解锁即投入运行；精炼厂未建成时转运矿石保持可售（收入不受损），建成后自动改送精炼缓冲；运输线动画与转运统计随解锁开启。

### P1

3. **自动出售**：交易面板新增「自动出售星尘矿」开关 + 保留数量（默认 50），超出保留量自动卖出；设置写入存档 v4。
4. **升级收益预览**：升级按钮下方显示「升级后 +X.XX 速率/秒」与「约 X 分钟回本」，按当前能源策略倍率与售价计算（纯函数 `upgradePreview`）。
5. **分步新手引导**：引导卡改为 4 步（出售矿石 → 升级采掘器 → 切换能源策略 → 解锁运输线），每完成一步推进，当前步骤对应卡片高亮，进度存 sessionStorage。
6. **能源策略反馈**：策略切换提示与面板新增对选中设施的实际倍率影响（如「采掘优先：对星尘采掘器 +35%」）。
7. **节奏优化**：首个事件触发从 3 分钟提前到 2 分钟；第二矿区解锁成本调整为 **1250 信用点 + 20 晶体**（pacing 实测 27 分 19 秒，落在 25–28 分钟目标窗口）。

### P2

8. 版本号统一为 v0.3（界面读取常量，README / package.json 同步）。
9. 事件触发时顶栏角标闪烁（自然事件与调试触发均生效）。
10. 事件通知条从右下角移到场景左下角，避免遮挡右侧面板操作区（本次验收发现会盖住自动出售复选框，已修复）。
11. 首启提示增加「点击场景设施查看详情」。
12. 成就 / 里程碑系统明确推迟到 v0.4。

## 四、接口与类型变更

- `types.ts`：`GameState` 新增 `settings: { autoSellStardust: boolean; stardustKeepAmount: number }`；存档版本 3 → 4。
- `config.ts`：新增 `GAME_VERSION`、`SECOND_MINE_UNLOCK_CREDITS`、`DEFAULT_STARDUST_KEEP`；`EVENT_FIRST_AFTER_MS` 120 秒；第二矿区 1250 信用点 + 20 晶体。
- `save.ts`：v3 → v4 迁移补充默认设置，并校验设置字段。
- `production.ts`：运输线解锁即转运，精炼厂未建成时矿石保持可售。
- `economy.ts`：新增 `applyAutoSell`。
- `hints.ts`：新增 `upgradePreview` 纯函数。
