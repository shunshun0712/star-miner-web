## 二、原计划书核心摘要

### 2.1 项目概述

《星际矿站》是一款原创的科幻放置经营游戏。玩家将在 Aurora-1 星球上修复采掘器、运输线和晶体精炼厂，通过自动生产、设施升级、能源策略和无人机事件扩展矿站。本版本由 Android 竖屏原型调整为 Windows 浏览器运行的 WebGL 桌面版。

### 2.2 平台与目标

- 平台：Unity 6 LTS WebGL
- 运行环境：Windows 10/11
- 支持浏览器：Chrome、Edge
- 推荐分辨率：1920×1080；最低可读分辨率：1280×720
- 交互方式：鼠标优先，键盘快捷键辅助
- 交付形式：WebGL 构建目录；运行方式：本地静态服务器
- 目标玩家：轻度休闲玩家；原型体验时长：约 30 分钟

首版不包含：Android APK、Android SDK/NDK/ADB/模拟器、账号系统、服务器存档、云同步、广告、内购、Steam 接入、联网多人功能。

### 2.3 核心玩法与生产链

生产链：**星尘采掘器 → 磁轨运输线 → 晶体精炼厂 → 信用点**

玩家通过以下方式推进游戏：观察矿站自动生产；收集信用点；升级采掘器、运输线和精炼厂；在三档能源策略之间做选择；处理无人机随机事件；解锁新的矿区；利用离线收益继续扩张矿站。

### 2.4 基础数值与公式

| 项目 | 初始数值 |
| --- | --- |
| 初始信用点 | 100 |
| 采掘速度 | 1.2 星尘矿/秒 |
| 运输速度 | 1.0 星尘矿/秒 |
| 精炼速度 | 0.25 晶体/秒 |
| 精炼配方 | 4 星尘矿 → 1 晶体 |
| 晶体售价 | 8 信用点 |
| 未精炼矿售价 | 1 信用点 |
| 离线收益上限 | 8 小时 |
| 设施最高等级 | 5 级 |

关键公式：

- 生产速度 = 基础速度 × 电力策略倍率 × [1 + 0.2 × (等级 − 1)]
- 容量 = 基础容量 × [1 + 0.25 × (等级 − 1)]
- 升级费用 = 基础费用 × 1.7^(当前等级 − 1)

### 2.5 电力策略（三档）

首版不模拟真实电力消耗，能源仅用于调整生产优先级：

| 策略 | 采掘 | 运输 | 精炼 |
| --- | --- | --- | --- |
| 采掘优先 | ×1.35 | ×0.90 | ×0.90 |
| 均衡运行 | ×1.00 | ×1.00 | ×1.00 |
| 精炼优先 | ×0.90 | ×0.90 | ×1.35 |

策略切换后，右侧面板、中央场景和资源变化提示必须在 5 秒内更新。

### 2.6 解锁节奏（30 分钟）

- **0—5 分钟**：采掘器自动运行，玩家看到星尘矿增长；完成第一次设施升级；学会切换能源策略。
- **5—12 分钟**：积累约 300 信用点；修复磁轨运输线；形成采掘器到运输线的生产链。
- **12—20 分钟**：积累约 1000 信用点；建造晶体精炼厂；形成完整生产链。
- **20—30 分钟**：积累约 2000 信用点；解锁第二矿区；看到第三矿区锁定预览（第三矿区作为后续内容目标，不在首版开放）。

### 2.7 无人机事件

- 每 3—5 分钟出现一次，采用二选一：
  - 选项 A：立即获得 50 信用点
  - 选项 B：所有生产设施在 30 秒内获得 ×1.5 速度
- 规则：事件不在离线期间生成；出现时不暂停生产；玩家未选择前不会自动结算；关闭弹窗不会自动选择奖励；事件奖励不会使资源变成负数。

### 2.8 视觉方向

采用已确认的 A「深空指挥舱」风格。视觉关键词：深空蓝背景、青色生产流光、紫色晶体效果、橙金色信用点与升级反馈、深色半透明面板、科幻工业仪表盘、明亮但具有太空氛围、高信息可读性、适合长期经营游戏。

设施状态标签：ONLINE / LOCKED / BUILDING / UPGRADING / OFFLINE。

### 2.9 宽屏界面与快捷键

界面结构：**左侧导航 + 中央矿站场景 + 右侧管理面板**，底部为状态栏。

- 顶栏：矿站名称、信用点、星尘矿、晶体、保存状态、WebGL 版本号
- 左侧导航：矿站、升级、星图、存档管理
- 中央场景：采掘器 → 磁轨运输线 → 精炼厂；设施状态、资源流动动画、生产效率提示、能源策略效果、无人机事件提示、设施升级动画
- 右侧面板：当前能源策略、三档策略按钮、设施等级/速度/容量、升级与解锁费用、不可用原因
- 底部状态栏：最近操作反馈、事件倒计时、离线收益提示、自动保存状态、错误提示

快捷键：

| 按键 | 功能 |
| --- | --- |
| 1 / 2 / 3 | 切换采掘优先 / 均衡运行 / 精炼优先 |
| U | 升级当前可升级设施 |
| M / S / G | 打开矿站页 / 升级页 / 星图页 |
| Esc | 关闭弹窗 |

规则：文本输入框获得焦点时不触发游戏快捷键；快捷键触发后必须显示反馈；鼠标与键盘共用同一套业务逻辑；不可用操作必须显示原因；快捷键不能绕过费用和解锁条件。

### 2.10 存档系统

- 存储方式：IndexedDB（浏览器本地存档）+ JSON 导入/导出（手动备份与迁移）。
- 存档内容：存档版本、信用点、星尘矿、晶体、各设施等级、设施解锁状态、当前能源策略、第二矿区解锁状态、最后保存时间、当前生产状态、事件状态、数据校验信息。
- 自动保存时机：游戏启动完成后、升级后、解锁设施后、切换能源策略后、无人机事件选择后、页面隐藏时、页面刷新/关闭前尽力保存、固定时间间隔自动保存。关键操作必须立即保存。
- 导入规则：JSON 格式错误拒绝导入；版本过旧尝试迁移；无法迁移拒绝导入；资源为负数拒绝导入；导入前不覆盖当前存档；导入成功后显示确认提示。

### 2.11 离线收益

- 离线时间 = 当前时间 − 最后保存时间；有效离线时间 = clamp(离线时间, 0, 28800 秒)。
- 时间倒退按 0 秒处理；离线收益最多累计 8 小时；离线期间不触发无人机事件、只计算生产收益；资源结算后不得低于 0；游戏启动时显示离线收益摘要。
- 启动流程：读取存档 → 校验存档 → 计算离线时间 → 结算离线收益 → 显示收益摘要 → 进入实时生产。

### 2.12 技术结构与数据流

复用现有核心模块：GameState、ProductionSimulator、EconomyService、EventService、OfflineSettlement、SaveRepository、IClock、BalanceConfig。

新增 WebGL 适配模块：

- WebSaveRepository：IndexedDB 读写、存档版本管理、保存失败提示、浏览器存储异常处理
- JsonSaveTransfer：存档导出/导入、JSON 格式校验、版本迁移、资源合法性检查
- WebClock：读取浏览器时间、计算离线收益时间、处理时间倒退、提供测试时间注入接口
- DesktopInputRouter：鼠标输入、键盘快捷键、输入焦点判断、页面导航输入、弹窗关闭输入
- StarMinerDesktopUi：顶栏、左侧导航、中央场景、右侧策略面板、设施管理卡片、事件弹窗、底部状态栏
- WebGlBootstrap：游戏启动、存档读取、离线收益结算、收益摘要显示、自动保存初始化、WebGL 错误提示
- BuildWebGlScript：Unity WebGL 构建、输出目录整理、生成本地运行说明、检查构建文件完整性

建议接口：

```csharp
public interface IAsyncSaveRepository
{
    Task<GameState?> LoadAsync();
    Task SaveAsync(GameState state);
    Task<string> ExportAsync(GameState state);
    Task<GameState> ImportAsync(string json);
}
```

存档仓库要求：读取失败不会静默覆盖存档；保存失败会显示提示；导入失败不改变当前状态；存档版本可迁移；所有写入数据经过资源非负校验。

数据流：打开 WebGL 页面 → IndexedDB 读取存档 → 校验版本与资源 → 计算最多 8 小时离线收益 → 显示离线收益摘要 → 进入实时生产 → 用户操作更新 GameState → 自动保存 IndexedDB → 玩家可导出 JSON 备份。

### 2.13 异常处理

- IndexedDB 读取失败：提示"无法读取浏览器存档，原有存档未被覆盖"，可开始新档或导入 JSON 备份。
- JSON 导入失败：提示"存档导入失败，当前游戏进度保持不变"，并给出错误原因。
- 浏览器时间倒退：离线时间按 0 秒处理，提示"检测到系统时间异常，本次未结算离线收益"。
- 页面加载失败：显示静态错误页，提示检查静态服务器、浏览器版本、WebGL 是否启用、构建目录是否完整。

### 2.14 构建输出

输出目录：`outputs/StarMinerWebGL/`，包含 index.html、Build/、TemplateData/、README-本地运行说明.md。

本地运行方式：在 StarMinerWebGL/ 目录启动静态服务器，用 Chrome 或 Edge 打开本地地址；不建议直接双击 index.html（避免资源加载失败、跨域限制、IndexedDB 异常、压缩资源无法读取）。

### 2.15 验证计划与验收标准

功能测试要点：首次打开可创建新档；已有存档可正确读取；离线收益最多累计 8 小时；时间倒退不产生收益；升级/解锁不会扣成负数；策略切换后 5 秒内显示倍率变化；无人机事件可正常二选一；JSON 可导出、可重新导入；错误 JSON 不覆盖当前存档；刷新后进度保持。

桌面交互测试要点：鼠标可正常操作；左侧导航可切换页面；右侧面板可显示设施状态；快捷键 1/2/3、U、M/S/G、Esc 生效；输入框聚焦时快捷键不误触发；1280×720、1366×768、1920×1080 下布局正常；浏览器缩放后中央矿站不被遮挡。

玩法检查点：0 分钟开始采掘并看到资源增长；5 分钟完成第一次升级；12 分钟解锁运输线；20 分钟形成完整生产链；30 分钟解锁第二矿区；30 分钟后显示第三矿区锁定预览。

验收标准：Chrome/Edge 正常加载 WebGL；本地静态服务器运行无资源加载错误；刷新后进度正确保留；IndexedDB 存档可用；JSON 导入导出可用；离线收益最多 8 小时；时间倒退不产生收益；资源不出现负数；策略切换后 5 秒内看到反馈；30 分钟体验节奏基本符合原计划；无需 Android 构建链；视觉风格符合 A「深空指挥舱」。

### 2.16 默认假设

首版采用 WebGL，不制作 Windows 独立 .exe；首要浏览器为 Chrome 和 Edge；首版保持单机离线体验；不接后端服务和账号系统；原有生产数值和 30 分钟解锁节奏保持不变；视觉方向采用 A「深空指挥舱」。

## 三、五维优化建议

### 3.1 玩法数值与策略深度

**现状**：三级生产链+三档能源策略的设计成立，但瓶颈反馈不够直观，策略仅为纯数值增减，决策感偏弱，玩家容易找到"最优解"后不再切换；玩家可直接售卖未精炼矿（4 矿 = 4 信用点），精炼后 1 晶体 = 8 信用点，收益翻倍但需 1000 信用点建厂，回本周期约 16 分钟，部分玩家可能长期卖原矿跳过精炼。

**竞品参考**：《Idle Miner Tycoon》通过传送带流速、矿车排队动画直观展示产能卡点；《放置工厂》用黄/红色状态标识提示瓶颈环节；《Idle Planet Miner》中高级矿区解锁、高阶升级必须使用精炼产物。

**建议**：

1. 增加**瓶颈状态标识**：某环节产出速度＞下一环节处理速度时，设施边框变黄/变红，运输线上出现资源堆积动画，让玩家一眼识别卡点，能源策略切换动机更强。
2. 给能源策略增加题材化风险：如「采掘优先」5% 概率触发设备过载、采掘器临时停机 10 秒；「精炼优先」有概率出现晶体损耗，让策略具备风险收益权衡。
3. **强化精炼必要性**：第二矿区解锁、设施 3 级以上升级必须消耗晶体，强制玩家推进到精炼环节。
4. 轻量"矿价波动"机制：原矿售价在 0.8—1.2 信用点随机浮动，晶体价格保持稳定，凸显精炼的收益稳定性价值。
5. **丰富无人机事件决策维度**：新增投入型（消耗 200 信用点，永久提升当前矿区采掘速度 5%）与风险型（60% 概率获得 100 信用点，40% 概率损失 30 信用点）事件；事件弹窗改为右下角非阻塞通知，不遮挡中央生产场景。

### 3.2 Web 桌面端体验

**现状**：仅区分"在线实时生产"和"离线收益"，未覆盖浏览器标签页后台挂起场景；Unity WebGL 默认包体偏大、加载时间长；快捷键覆盖基础功能，但未充分发挥宽屏和鼠标优势。

**竞品参考**：成熟 Web 放置游戏支持"后台标签页按离线规则计算"；头部 Web 放置游戏（如《Cookie Clicker》）首屏加载控制在 3 秒以内；《异星工厂》等桌面经营类游戏支持悬停详情、滚轮缩放、快捷批量操作。

**建议**：

1. 监听 `visibilitychange` 事件：页面隐藏超过 1 分钟后自动切换为离线收益计算模式，切回时结算收益并显示摘要；可选接入浏览器通知 API（事件触发、离线收益达上限时推送桌面通知）。
2. **加载分级**：先显示极简加载页+进度条，优先加载 UI 和核心数值逻辑，后台异步加载 3D 场景资源；原型阶段降低模型精度、关闭冗余粒子效果，控制总包体在 15MB 以内。
3. 增加"低配模式"开关：一键关闭流光、粒子等视觉特效，仅保留 UI 数值运行。
4. **桌面交互细节**：悬停设施显示详细产出公式、升级收益预估；扩展快捷键 Q/W/E（对应采掘器/运输线/精炼厂升级）、空格（暂停/继续）；滚轮缩放中央场景；屏蔽浏览器右键默认菜单，替换为游戏内快捷操作。

### 3.3 反馈与留存感

**现状**：升级、解锁仅数值变化，视觉反馈较弱；离线收益摘要感知不强。

**竞品参考**：《Idle Miner Tycoon》升级后设备外观、运行速度有显著变化，解锁新区域有镜头推进动画；头部放置游戏离线收益普遍做"数字滚动+分项明细"。

**建议**：

1. 升级/解锁瞬间增加**短动画+数值跳变特效**（等级数字跳动、设施亮起过载光效、生产流光提速、轻量音效）。
2. 关键节点（首次打通全产业链、解锁第二矿区）弹出**里程碑卡片**，显示"用时 XX 分钟"，30 分钟原型至少设置 3 个里程碑节点。
3. 离线收益弹窗**分项列出**采掘、运输、精炼的单独产出，配合数字从 0 滚动到最终值的动画（2—3 秒）。
4. 离线收益接近 8 小时上限时，底部状态栏提前提示"离线收益即将达上限，记得上线领取"。

### 3.4 原型验证与可维护性

**现状**：验证计划依赖手工测试，调整数值需要改代码重新构建，效率较低；IndexedDB 依赖浏览器存储，清理缓存即丢失存档。

**建议**：

1. 内置**开发者调试面板**（通过 `~` 键等隐藏快捷键呼出）：支持修改资源数量、跳级设施等级、手动触发无人机事件、模拟离线 N 小时。
2. 增加轻量**埋点**：自动记录关键操作时间点（首次升级、解锁运输线、解锁精炼厂等），可导出 CSV，用于验证 30 分钟解锁节奏。
3. 首次关闭页面前弹出提示："浏览器清理数据会丢失存档，建议导出 JSON 备份"，并附带导出按钮。
4. 存档导入增加**预览功能**：导入前显示存档内的资源、等级信息，确认后再覆盖。

### 3.5 题材差异化与迭代预留

**现状**：题材仅体现在美术风格，玩法与普通放置矿工同质化较高。

**建议**：

1. 首版加入**星球环境事件**：如随机触发"太阳风暴"，全设施速度降低 20% 持续 1 分钟；均衡能源策略受影响减半，贴合科幻题材并反向强化能源策略价值。
2. 第二矿区设定为不同矿石类型（如氦-3 矿区），首版仅做命名和视觉区分，为后续差异化玩法预留空间。
3. **配置化设计**：生产设施参数、事件模板、矿区数据做成可配置文件（ScriptableObject 或 JSON），新增内容无需修改核心代码。

## 四、P0/P1/P2 落地优化清单

**分级标准**：

- **P0 首版必做**：直接影响核心玩法成立、Web 端基础可用性、30 分钟原型验证目标，开发成本可控，必须纳入本次原型开发
- **P1 建议首版落地**：提升体验质感与留存感知，开发量小、收益高，优先安排进首版排期
- **P2 后续迭代项**：用于正式版本扩展，首版原型可不做，预留设计接口即可

### 4.1 玩法数值与策略模块

**P0 首版必做**

1. **强化精炼环节的必要性**
   - 落地规则：设施升至 3 级及以上、解锁第二矿区，必须同时消耗信用点+晶体；原矿售卖功能保留，但不再能支撑核心成长路径
   - 目的：确保玩家在 20 分钟节点必然推进到精炼厂，验证完整生产链的设计目标
2. **生产瓶颈可视化反馈**
   - 落地动作：上游产出速度＞下游处理速度时，对应设施边框变为橙色预警，运输线显示资源堆积动画；右侧面板对应设施卡片标注「瓶颈」标签
   - 目的：让能源策略切换有明确决策依据，避免策略沦为无意义的数值开关

**P1 建议首版落地**

1. **无人机事件改为非阻塞形式**：全屏弹窗改为右下角悬浮通知条，不遮挡中央生产场景；玩家可随时点开选择，未选择时事件持续挂起不消失
2. **新增 1 类决策型事件**：「投入型」事件——消耗 200 信用点，永久提升当前矿区采掘速度 5%（首版全局仅触发 1 次）

**P2 后续迭代**

1. 能源策略加入风险机制：采掘优先 5% 概率触发设备过载停机 10 秒；精炼优先有概率出现晶体损耗
2. 原矿价格轻量波动：售价在 0.8—1.2 信用点区间随机浮动，晶体价格保持稳定

### 4.2 Web 桌面端专项体验

**P0 首版必做**

1. **浏览器后台标签页适配**：监听 `visibilitychange` 事件，页面隐藏超过 1 分钟后自动切换为离线收益模式；切回时结算收益并弹出摘要
2. **WebGL 加载分级与体积控制**：优先加载 UI 框架与核心数值逻辑，后台异步加载 3D 场景与特效；原型阶段关闭冗余粒子效果，控制总包体在 15MB 以内

**P1 建议首版落地**

1. **桌面端交互细节增强**：鼠标悬停设施显示详细产出公式、升级收益预估；扩展快捷键 Q/W/E（设施升级）、空格（暂停/继续）；屏蔽游戏区域内浏览器右键默认菜单，替换为快捷操作面板
2. **浏览器通知推送（可选开关）**：离线收益达上限、无人机事件触发时通过浏览器通知 API 推送桌面提醒，玩家可手动开启/关闭

**P2 后续迭代**

1. 低配模式开关：一键关闭所有视觉特效，仅保留 UI 数值运行
2. 中央矿站场景支持滚轮缩放、拖拽平移

### 4.3 反馈与留存感

**P0 首版必做**

1. **关键节点里程碑提示**：30 分钟体验内设置 3 个里程碑（首次升级、打通运输线、建成完整生产链），达成时弹出里程碑卡片并显示用时时长
2. **离线收益明细化呈现**：启动弹窗分项列出采掘、运输、精炼的单独产出，配合数字滚动动画（2—3 秒），替代单一总数值

**P1 建议首版落地**

1. **升级操作的仪式感反馈**：升级瞬间增加等级数字跳动、设施光效提亮、生产流光提速的短动画，配合轻量音效
2. **离线收益上限预警**：离线收益累计达 7 小时，底部状态栏常驻提示「离线收益即将达上限，记得上线领取」

**P2 后续迭代**

1. 轻度成就系统：累计产出、升级次数、事件选择等成就收集
2. 生产数据统计面板：展示每分钟/每小时产出、历史总收益

### 4.4 原型开发与验证效率

**P0 首版必做**

1. **内置开发者调试面板**：通过隐藏快捷键（`~` 键）呼出，支持修改资源数量、跳级设施等级、手动触发事件、模拟离线 N 小时
2. **关键节点自动埋点**：自动记录首次升级、解锁运输线、建成精炼厂、解锁第二矿区的时间点，支持导出 CSV 文件

**P1 建议首版落地**

1. **存档导入预览功能**：导入 JSON 前先显示存档内的资源、等级、解锁状态，玩家确认后再覆盖当前进度
2. **首次退出备份提示**：玩家首次关闭页面前弹出提示「浏览器清理数据会丢失存档，建议导出 JSON 备份」，并附带一键导出按钮

**P2 后续迭代**

1. 多存档位支持：支持 3 个本地存档槽，方便测试不同成长路线
2. 数值全配置化：设施参数、事件模板、矿区数据全部改为可配置文件

### 4.5 题材差异化与扩展性

**P1 建议首版落地**

1. **星球环境事件基础版**：随机触发「太阳风暴」事件，全设施速度降低 20% 持续 1 分钟；均衡能源策略受影响减半
2. **第二矿区差异化包装**：第二矿区设定为氦-3 矿区，矿石外观、UI 配色做区分，生产数值保持与第一矿区一致

**P2 后续迭代**

1. 矿区差异化玩法：不同矿区有不同的资源特性、事件类型、能源适配性
2. 全局科技树系统：解锁永久加成，延伸长线成长空间

## 五、与《采矿大亨（Idle Miner Tycoon）》系统对比

《采矿大亨》是放置采矿品类的市场标杆，其三段式生产链、瓶颈平衡设计、阶梯式自动化等核心机制经过长期验证。以下从 5 个核心维度对比，并给出可落地的借鉴方向。

### 5.1 核心生产链设计

**采矿大亨**：采用**挖掘→电梯运输→地面售卖/精炼**三段式链路。核心逻辑是"用可视化瓶颈倒逼策略决策"：每一环独立运转，上游产出超过下游运力时矿石直观堆积在转运点（矿箱堆满、工人排队），无需计算即可一眼识别卡点；初始为手动操作，**全自动化是中期核心解锁目标**而非初始标配；不同矿区矿石价值差异极大，解锁高价值矿区是长线成长的核心动力。

**星际矿站现状**：采用**采掘器→磁轨运输线→晶体精炼厂→信用点**的三段生产+一级变现链路，逻辑自洽，但缺少直观的瓶颈视觉反馈，玩家只能靠数值推算卡点；初始即全环节自动化，缺少"解锁自动化"这一成长目标；能源策略与生产瓶颈联动不足，策略价值未充分释放。

**借鉴建议**：

1. **P0 必做：落地瓶颈可视化**——上游产出速度＞下游处理速度时，运输线出现资源堆积动画、设施边框变橙色预警、右侧面板标注「瓶颈」标签，这是最低成本提升策略感的方案。
2. **P1 建议：补充半手动过渡阶段**——0—5 分钟新手期采掘器自动运行，但矿石需手动点击转运；解锁磁轨运输线后才实现采掘—运输全自动化。

### 5.2 自动化与离线收益

**采矿大亨**：三个环节需分别雇佣对应经理（矿区主管、升降调度员、地面协调员），全部配齐才能实现全链路离线生产；未雇佣经理的环节离线期间不产出。"雇到第一个经理"是前期核心爽点。基础离线收益上限 6 小时，且收益效率低于在线，可通过道具、升级延长。

**星际矿站现状**：初始全环节自动，离线 8 小时全额结算，对轻度玩家更友好，但前期缺少自动化解锁目标，成长颗粒度偏粗；Web 端适配考虑周全（后台挂起、时间倒退等），比多数移动端移植产品严谨。

**借鉴建议**：

1. **首版适配方案**：保持全自动化基础设定，契合 30 分钟轻体验定位；新增"设施 3 级解锁【无人值守】加成"——升级到 3 级后该设施离线收益效率提升 20%，把离线收益和升级成长挂钩。
2. **后续迭代方向**：参考经理系统加入「AI 运维模块」，不同模块对应不同生产环节的离线效率加成、事件自动处理能力，作为中期核心成长目标。

### 5.3 数值成长与升级体系

**采矿大亨**：**里程碑式非线性成长**——设置 10/25/50 级等关键阈值，达成后跳阶提升（矿工数量翻倍、设备外观迭代、单次产出大幅跃升）；升级费用指数增长，同时提供"升 10 级/升满"批量升级；经典资源权衡——升级现有设施边际收益递减，解锁新矿区基础收益更高但投入巨大。

**星际矿站现状**：线性成长（每级固定 20% 速度、25% 容量加成，最高 5 级），曲线平缓，缺少跳阶式爽感峰值；仅支持单级升级、无批量操作；第二矿区偏内容延伸，未体现与"升级现有设施"的策略权衡。

**借鉴建议**：

1. **P1 建议：设置等级里程碑**——保留 5 级上限做差异化：3 级时设施外观、光效明显迭代，生产流光亮度提升；5 级时解锁「超频模式」，基础速度额外 +30%，同时附带小概率临时停机风险。
2. **桌面端适配优化**：增加"一键升级到当前可升最高级"按钮，减少重复点击。
3. **第二矿区策略化设计**：设定为"基础产出更高，但升级费用是第一矿区的 1.5 倍"，形成"稳扎稳打 vs 高投入高回报"的选择。

### 5.4 事件与加速系统

**采矿大亨**：随机事件同时包含正向（发现稀有矿脉）和负向（塌方、设备故障）；搭配主动加速手段——经理「狂热模式」（60 秒翻倍加速，带冷却）、收益道具卡，玩家可主动把控节奏；狂热模式有专属视觉特效、数值跳变、音效配合，是核心留存爽点。

**星际矿站现状**：仅无人机随机事件，两个选项均为正向福利，无风险决策成本；无主动加速手段，玩家只能被动等待。

**借鉴建议**：

1. **P0 必做：强化加速事件的反馈强度**——将无人机事件的"生产加速"选项参考狂热模式做视觉升级：全场景生产流光提速、设施边框泛光、产出数值字体放大。
2. **P1 建议：新增主动加速技能**——「应急能源过载」技能：冷却 10 分钟，全设施 30 秒内速度 ×2；与能源策略联动——采掘优先模式下冷却缩短 20%。
3. **后续迭代**：加入轻度负面事件（如"太阳风暴""矿物堵塞"），均衡能源策略受负面影响减半，让策略具备风险对冲价值。

### 5.5 界面交互与信息层级

**采矿大亨**：**所见即所得**——核心场景即操作区，点击设施直接弹出升级面板，无需切换页面；可升级设施有醒目的金色箭头/红点提示；设施等级、运行状态、产出速度直接标注在场景内，信息效率极高。

**星际矿站现状**：宽屏三栏布局信息承载量大、适配桌面端，但操作路径偏长——升级需切换到左侧导航的升级页面，无法直接在场景中操作；设施状态有 ONLINE/LOCKED 等标签，但等级、升级提示未直接体现在场景中，引导性偏弱。

**借鉴建议**：

1. **P1 建议：缩短操作路径**——点击中央场景的任意设施，右侧管理面板自动切换为该设施的详情与升级界面；左侧导航仅保留星图、存档等全局功能，日常操作全部在"中央场景+右侧面板"完成。
2. **强化升级引导**——设施满足升级条件时，场景中的设施上方显示金色向上箭头提示，不用切面板就能知道"有东西可以点"。

### 5.6 对比总结

《星际矿站》基础框架完整，Web 桌面端定位清晰，能源策略、存档系统有自己的设计亮点。与《采矿大亨》相比，核心差距集中在**成长阶梯颗粒度、瓶颈反馈直观性、操作爽感强度**三个方面。

首版原型优先落地「瓶颈可视化 + 升级里程碑反馈 + 加速事件强特效」三点，即可大幅接近成熟产品的核心体验，同时保留科幻题材和桌面端的差异化优势。

## 六、综合结论与首版落地建议

### 6.1 首版 P0 必做项汇总（直接影响原型验证目标）

1. 强化精炼环节必要性（设施 3 级以上、解锁第二矿区消耗晶体）
2. 生产瓶颈可视化（设施橙色预警 + 运输线堆积动画 + 「瓶颈」标签）
3. 浏览器后台标签页适配（`visibilitychange` + 1 分钟切换离线收益模式）
4. WebGL 加载分级与体积控制（总包体 ≤ 15MB）
5. 关键节点里程碑提示（3 个里程碑 + 用时卡片）
6. 离线收益明细化呈现（分项 + 数字滚动动画）
7. 内置开发者调试面板（`~` 键呼出）
8. 关键节点自动埋点（可导出 CSV）
9. 强化加速事件反馈强度（参考狂热模式的视觉升级）

### 6.2 首版 P1 建议项汇总（工作量小、收益高，优先排期）

1. 无人机事件改为右下角非阻塞通知条
2. 新增「投入型」决策事件（200 信用点 → 永久 +5% 采掘速度，限 1 次）
3. 桌面交互细节增强（悬停信息、Q/W/E、空格暂停、屏蔽右键菜单）
4. 浏览器通知推送（可选开关）
5. 升级操作的仪式感反馈（短动画 + 轻量音效）
6. 离线收益上限预警（7 小时常驻提示）
7. 存档导入预览 + 首次退出备份提示
8. 星球环境事件基础版（太阳风暴）与第二矿区差异化包装（氦-3）
9. 等级里程碑设计（3 级外观迭代、5 级超频模式）
10. 一键升级到最高级按钮
11. 第二矿区策略化（基础产出更高、升级费用 ×1.5）
12. 「应急能源过载」主动加速技能（冷却 10 分钟，×2 速度 30 秒）
13. 缩短操作路径（点击场景设施联动右侧面板）+ 金色升级箭头引导
14. 半手动过渡阶段（0—5 分钟手动转运矿石）

### 6.3 下一步建议

1. 确认首版 P0 + P1 的取舍范围，将 P1 项按"开发量 / 收益"排序后纳入排期。
2. 基于《采矿大亨》成熟数值模型，重排一版 30 分钟体验的解锁节奏和升级数值表（重点：里程碑阈值、批量升级、离线收益与升级挂钩）。
3. 将 P2 项（能源策略风险机制、矿价波动、低配模式、成就系统、统计面板、多存档位、数值配置化、矿区差异化、科技树等）登记为后续迭代 backlog，预留数据接口。
4. 开始 WebGL 原型搭建时，优先落地 P0 项，并以埋点数据验证 30 分钟节奏是否符合预期。
